# Assets

This directory stores source assets, attribution records, and asset-pipeline documentation.

Runtime assets may be colocated with their owning game content when that improves maintainability, but every third-party or generated asset must still be recorded in `ATTRIBUTION.md`.

Do not add assets with unknown provenance, unclear commercial-use rights, or license terms that conflict with the project. Agents cannot accept marketplace terms or purchase assets on behalf of the owner.
